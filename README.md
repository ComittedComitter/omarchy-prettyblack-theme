# PrettyBlack

A near-black Omarchy theme but colors are still colors. muted though.

## Install

```bash
omarchy theme install https://github.com/ComittedComitter/omarchy-prettyblack-theme.git
```

Omarchy will clone the repo as **Prettyblack** and apply it.

## Files

- `colors.toml` — palette used to generate terminal, shell, and app theming
- `icons.theme` — icon theme (`WhiteSur`)
- `preview.png` — shown in the Omarchy theme selector
